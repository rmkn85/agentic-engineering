# Independent correctness and framing review

Verdict: changes required. The preserved acceptance criteria are in `criteria.json`; exact reviewed file hashes are in `reviewed-identity.json`. Review covered candidate commit `5726a380f8a7ec85eed3effa41928c892153026b` plus the identified uncommitted integration files. Six isolated mechanical reproductions ran successfully, demonstrating the defects below. These are not native behavioral trials.

1. **P1 — Native results are not bound to the workspace the completed run produced.** `tools/native_trial.py:193-224` scores the current working files while attributing the result to the last completed process. No completed-run tree identity is recorded or checked. Repairing the consumer externally after that process ends yields `passed: true` and assistance count zero. `run` also accepts repeated execution against an already modified fixture, labels it fresh, and initializes assistance to an empty list. Record before/after workspace identities per attempt, reject stale scoring, and distinguish fresh attempts from continued/retried or externally modified work. Tests: `test_native_score_attributes_later_external_repair_to_completed_run`, `test_repeated_run_reuses_modified_fixture_and_still_has_zero_assistance`.

2. **P2 — An accepted report can survive replacement of its requirement frame.** `tools/check_review.py:44-50` validates the current frame but never compares its identity with the one accepted by the unchanged manifest/report. Replace request and failure evidence, reseal different criteria, and the old accepted report still covers the code. Bind the accepted manifest/report to the framing receipt and original authority identities. Test: `test_old_accepted_report_survives_replaced_frame_and_request`.

3. **P2 — Review coverage omits actual methodology controls.** `tools/check_review.py:17-21` excludes control documentation under `docs/execution`, the maintained `tools/make` activity wrapper, and recurrence fixtures. Changes to all three pass without review. Define coverage from maintained control surfaces while keeping unrelated product changes cheap. Test: `test_changed_methodology_surfaces_need_no_review`.

4. **P2 — Ignored intervention evidence can change without invalidating correction.** `tools/goal_control.py:92-99` binds local acceptance evidence but not local reflection-intervention evidence. A valid intervention citing `.agent/failure.txt` reaches verified status; replacing that evidence with a new contradictory failure leaves the receipt verified. Bind supporting evidence automatically, including ignored paths accepted by the intervention schema. Test: `test_reflection_evidence_replaced_after_supported_result_stays_verified`.

5. **P2 — Maintained trial execution cannot provide required hook-trust evidence.** `tools/reflection_activity.py:ACTIVITIES` exposes only AUDIT for recurrence-run, whereas `native_trial.run` refuses configured hooks without a trust receipt. Passing TRUST_RECEIPT through the native activity is rejected. Add a constrained receipt parameter without granting trust or changing host policy. Test: `test_native_activity_cannot_supply_required_hook_trust_receipt`.

Run the reproductions with `python3 reproduce.py`; `reproduction.log` retains results. They use disposable repositories and deterministic mocked host completion where stated, without network or live project effects.

The design improves contract pinning and makes correction execution observable. It appropriately limits causal claims and distinguishes configured hooks from observed invocation. Nevertheless, native adherence, real host response handling, continuation behavior, false-completion classification, and comparative efficiency remain unproved. A zero process exit alone is insufficient evidence for those claims. The reported native smoke stopped before model execution because host installation/state was read-only; this is an execution limitation, never behavioral proof. Root AGENTS/Make editability is intentionally part of the task and is not reported as a defect. The held-out oracle remains unopened during this review.
