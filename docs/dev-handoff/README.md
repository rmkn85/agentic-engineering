# Agentic Engineering continuation

The delegation launch preflight now requires explicit model, reasoning effort
and context selection when supported. Routine review against an established
rubric starts on the cheapest capable exposed tier; visual work alone does not
justify a frontier model or maximum reasoning. Full-history forks and follow-ups
can retain an expensive parent/worker configuration, so check the actual launch
mode before dispatching.

The efficient-execution skill and local Codex delegation guide carry this rule.
This is a guidance change, not a modification to platform defaults or a measured
cost improvement. A bounded reference reader was launched with an explicit
lower-cost model, low effort and empty history; the runtime did not expose resolved
inference settings. Whitespace validation passed; no test suite or cost benchmark
was run for this documentation change.
