# Agentic Engineering continuation

Integrated product work now has a concise direct-delivery method in
`docs/execution/direct-delivery.md`, reached from the operating corpus and
`skills/efficient-execution/SKILL.md`. It connects current user intent to decisive
scenarios, existing ownership, early installed verification and full completion.
It also reconciles stale continuation text and selects performance work by its
plausible whole-operation effect. Existing correctness and acceptance remain binding.

Delegation defaults remain Luna/Sol. `docs/local-codex/subagents.md` now explicitly
supports an owner-authorized sustained co-developer lane, including Astra High,
for substantial independent work. The exception does not cover small transient
workers, invent authorization or bypass higher-priority runtime restrictions.
AGENTS, operating corpus and skill use the same boundary.

This is a guidance change. `make check` passes 108 native tool tests; link/whitespace checks and a bounded
independent semantic review pass. These qualify the guidance change;
no runtime default was altered and no measured delivery-cost improvement or
cross-project adoption is claimed. Subsequent real delivery must establish whether
the method reduces repeated clarification and rework while preserving acceptance.
