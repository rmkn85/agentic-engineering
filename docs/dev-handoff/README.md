# Agentic Engineering continuation

The outcome/evidence update extends the existing direct-delivery, recovery,
observation and adoption owners. It distinguishes implemented, verified,
integrated, available and accepted claims where applicable; checks necessity
before new public interfaces; binds consequential claims to native verdicts,
actual loaded identity and complete enough evidence; and refreshes mutable facts
when their relevant conditions change. Root `AGENTS.md` is unchanged. Resource
lifecycle is the only new operational procedure, loaded on demand.

`quiet-run` now scopes PASS/FAIL to process exit and leaves substantive acceptance
unassessed. Recall keeps ordinary bytes compatible and adds opt-in JSON coverage,
exact bytes and hash-bound continuation. Benchmark reporting distinguishes worker,
evaluation and measured setup-through-evaluation intervals. Worktree retirement
preserves dirty/untracked/ignored state, hidden index flags and unique HEAD/reflog
commits; successful retirement uses no force. The producer must be stopped and
retained work harvested before later cleanup.

See [trial evidence](../../experiments/outcome-evidence-control.md) and
[research rationale](../../references/outcome-evidence-control-2026-11.md).
The native suite ran 214 tests successfully with one skip. A candidate-only Luna
Medium release repair changed a seeded public-test-green/consumer-wrong result
into protected independent acceptance. That trial explicitly loaded the core;
it does not prove automatic host loading, detailed procedure adherence, actual
workspace delivery or measured efficiency gains. The review found no actionable
code issues; changed links and the complete public text corpus were checked.

Adopt through the existing newcomer/native routes, preserving local adaptations.
Use the next authorized connected delivery to verify actual instruction receipt,
behavior and accepted consumer result. Keep unrun host, product and experiential
layers open; passing tool tests or matching instruction copies cannot close them.

The portable contributor core now defines five engineering personas and selects
them by the responsibility exercised in the current request. The operating corpus
links that definition. Ordinary service restoration is an Operator concern handled
by engineering; role labels confer no permissions or new approval gates. Adopt
through existing local snapshots while preserving project rules. Wording and
instruction-route checks establish the published definition; sustained agent
adherence remains observable during ordinary work.

Integrated product work follows `docs/execution/direct-delivery.md`. The current
refinement prioritizes common user journeys and the next connected deliverable,
ties enabling work to concrete outcome gaps, and keeps process support compact.
The 80/20 and nested 70/30 ratios are qualitative judgment guides; full acceptance
and binding safety/permission conditions remain intact. Existing task fields
carry the outcome, scenario, deliverable, implementation/interfaces and finish.

The detailed method stays in direct delivery. Steering, efficient-execution and
the portable contributor core point to it or supply a compact local fallback.
Context uses an enduring core, current outcome/progress/next action and relevant
evidence retrieved on demand. Reports lead with usable capability. Existing
ownership, routing, bounded recovery and completion boundaries remain binding.
No new task schema, ledger, quota checker or qualification stage was introduced.

Shared machine boundaries now have an on-demand practice in
`docs/interfaces/machine-contracts.md`, linked from specification, interface and
newcomer routes and summarized in the portable contributor core. Adopt it
incrementally through the existing semantic owner and local release/acceptance
routes. Independent consumer and provider work can use contract examples and
mocks; provider integration and product acceptance remain separate evidence.

Shared publication does not authorize editing unrelated consumer workspaces or
personal settings. The next useful evidence remains application during authorized
integrated delivery: whether the selected work closes the common journey gap
while preserving required contrasts and boundaries.
